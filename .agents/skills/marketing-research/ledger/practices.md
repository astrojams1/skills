# Practices register

Every practice the research arm has found for agents driving marketing. Update a row in place as its evidence or its
results change; add new rows at the bottom with the next id. Results link to each business's private register; no
counts or names here, since this repository is public.

Status: `watching` (evidence only), `handed off` (in a brief), `trying at <business>`, `kept at <business>`,
`retired at <business>`. A practice can carry one status per business.
