## Lessons

- 2026-11-05: Cloud sessions reach App Store Connect, Google and 1Password over the network, and have Chromium and ffmpeg, but hold no `op` and no service-account token. The vault is the only gap. Probe a cloud environment instead of assuming: the first plan assumed less than was true.
- 2026-11-05: A routine created without `mcp_connections` receives every connected account, PayPal and Gmail included. Clear them.
- 2026-11-05: Creating the daily Mac pass as a scheduled task was refused by the auto-mode permission classifier, with no reason given. Do not rebuild it as a LaunchAgent, cron job or hand-written task file: that decision is the owner's.
- 2026-11-05: The owner then approved the Mac pass in chat and the same task was created. Asking was the right route around a refusal.
- 2026-11-07: The owner's calendar marks timed plans "free" (transparent), so free/busy that trusts transparency sees an empty week. `gcal.mjs` counts every timed event as busy.
- 2026-11-07: The `calendar.events` scope cannot read `calendars/primary` (403 insufficient scopes). Read the calendar's name from an events listing, and store the refresh token before any other call, or a failed call loses the token.
- 2026-11-10: A scheduled task's stored prompt that restates the skill outlives the skill's changes. The 1.7.0 "do every item" rule never reached the Mac pass because its prompt still carried "three small items", and three runs logged "Budget of three small items". Keep the steps in the skill and the prompt a pointer.
- 2026-11-10: "No free slot" is a publishing constraint, not a production one. Deferring production until a slot opened left the queue empty whenever the one browser-recordable app was not due.
- 2026-11-10: A `finding` that describes a problem reads like work done, so a run that logs one feels finished. Make the ledger refuse an open issue without a blocker, and make the end report list what is left open, so leaving one is visible and has to be justified.
- 2026-11-12: Apple's Analytics Reports repeat a date in two or three daily instances, and the newest replaces it. Adding instances doubled the totals within a week. Store per-date values and sum unique dates.
- 2026-11-12: A channel without an outcome number cannot be learned from, so Learn never fired. Give every channel a download number before running it, and a rule that stops it.
- 2026-11-12: A gate that waits on the owner does not hold a run back; it fills `left_open` for days. Drop owner-only work and make the ledger refuse it.
- 2026-11-12: Email pitches sat "not operable" for want of a postal address, and runs kept raising it. Once the owner rules on a gate, record the ruling in his words where the gate was and never raise it again.
- 2026-11-12: A run must not depend on a call its environment refuses. The cloud's safety check blocks a call that sends mail, so the sending moved to a workflow the merge starts, and the run only reads.
- 2026-11-12: Raw page views overstate tap-through when visitors come from a website or an unknown source, which have no impression. Divide only App Store search and browse page views by impressions.
